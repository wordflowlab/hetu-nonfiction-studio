# 纪实写作

从河图稳定CLI/MCP发现活动包、当前作品和实际Schema，先读已有工程、固定来源与意见，再执行目标。包内方法随插件发现，不另装Codex插件或MCP服务。

按[专业旅程](references/workflows.md)选择模式，[操作地图](references/operations.md)定位当前参数。Evidence固定原始source_index及UTF-8区间，原话和原件只追加、不覆盖。Turn关联明确说话人与固定引文。Claim固定段落摘要及原文锚点，改稿后显示待复核。Link区分支持、反证与背景；Assessment固定主张及证据组合摘要，只追加，证据关系或描述变化后显示过期。存在反证时不能记录为无争议支持；核实状态是记录者判断，不替代事实和作者决定。

保存携带CAS与原键，未知先get_operation，成功后回读固定修订。专业工程与正文采纳分开，外发、费用、正式选用与定稿按本次作者决定执行。
