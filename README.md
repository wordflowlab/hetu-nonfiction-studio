# 纪实写作

> 河图洛书专业插件，把采访原话、文章主张、支持与反证及核实记录联系起来，沿固定稿件继续修改。

## 简介

纪实写作的难点是知道一句话依据什么、谁说过、有哪些不同说法，以及改稿后之前的核实是否仍适用。Agent可以组织采访和写作，软件保存固定引文、主张与核实快照，减少每轮重读全部材料的成本。

外部Agent经河图稳定CLI/MCP操作，作者阅读、比较与提意见。包内Skill随活动插件发现，专业成果、来源及修订可继续使用。

## 快速上手

Node.js 25、npm及河图0.12.6或更新版本。

```bash
npm ci
npm run build
npm run check
npm run test:unit
npm run package
```

正式宿主和运行包由acceptance-lock.json固定，安装后从河图稳定入口发现本包，不另安装Codex插件。

## 边界

不把证据数量、来源格式或Agent判断当事实认证；不执行外部抓取、联系受访者、发布或代签授权。研究台拥有研究问题与观察，本包拥有文章主张及核实过程；传记拥有人物生平和身份辨析。
