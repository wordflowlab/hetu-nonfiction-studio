# Skill与机器接续

包内`hetu-nonfiction-studio`通过河图稳定plugins.inspect、capabilities和skills.read动态发现，不创建Codex插件或独立MCP服务。安装／升级／启用后重新发现，旧包绑定不能继续使用；工具可见不等于获权读取任何作品。

默认旅程：固定采访／文件→保留原话与来源说明→准备稿件和主张锚点→关联支持与反证→记录固定核实判断→局部改稿与复核→文章和核实本。方法选择、阅读范围和判断依据由外部Agent负责，专业确定性规则由本包执行。先读现有成果和公开意见，不能为了演示创建另一份工程替代接续。

Evidence固定原始source_index及UTF-8区间，原话和原件只追加、不覆盖。Turn关联明确说话人与固定引文。Claim固定段落摘要及原文锚点，改稿后显示待复核。Link区分支持、反证与背景；Assessment固定主张及证据组合摘要，只追加，证据关系或描述变化后显示过期。存在反证时不能记录为无争议支持；核实状态是记录者判断，不替代事实和作者决定。

保存保留CAS与原键，未知先get_operation，成功后回读固定修订。每阶段准备create_handoff的固定依据与下一步问题；其他专业插件按实际安装Schema独立发现，缺能力不能伪造交接成功。费用、外发、正文采纳、正式设定和定稿沿作者真实决定处理。

Skill入口保持精炼，专业方法归references/workflows，操作地图由正式清单生成。专业清单和Schema由本仓库维护，宿主地图只导航公共入口。
